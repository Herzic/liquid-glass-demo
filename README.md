# Liquid Glass для веба — v3

Эффект «жидкого стекла» в духе iOS 26 для сайтов, без зависимостей. Сцена: **9 КБ gzip**, полный пакет вместе с классическим API v2 — 15,6 КБ gzip.

**Демо:** https://herzic.github.io/liquid-glass-demo/demo/ (рассчитано на телефон)

## Что нового в v3

- **Единая сцена `GlassScene`.** Все стеклянные элементы рисуются **одним** draw-call (instanced-квады по их рамкам) в одном полноэкранном WebGL2-холсте. Копирований между canvas нет.
- **Жидкое слияние.** SDF smooth-union между формами: линза «вытекает» в таб-бар и в кнопки, как капля. Группы задают, что с чем может сливаться.
- **Пружинная физика.** Нажатие упруго увеличивает элемент с перелётом и вспышкой блика. При перетаскивании линза **растягивается вдоль скорости** (анизотропная деформация с поворотом), и шейдер повторяет ту же матрицу, что CSS-трансформация содержимого.
- **Блик от наклона устройства** (DeviceOrientation; на iOS разрешение запрашивается по нажатию кнопки «наклон») **или от указателя.** Направление света сглаживается пружиной.
- **Внешний вид ближе к Apple.** Стекло прозрачнее и светлее; узкая полоса линзирования; тонкая яркая кромка, самая сильная на стороне света и отражённая с противоположной; мягкая внутренняя тень и внешняя тень. **Адаптивный тон**: над светлым фоном стекло молочно-светлое и текст тёмный, над тёмным — стекло темнее и текст белый. Сравнение с официальными изображениями Apple — `shots/apple-vs-ours.png`.
- **Преломление прокручиваемого контента — и на iPhone тоже.** Сцена понимает два слоя: обои (`background`) и прокручиваемый **canvas-лист с контентом** (`sheet`). Позиция листа читается из `getBoundingClientRect()` каждый кадр, поэтому при прокрутке **ничего не загружается заново**, меняется только uniform. Стекло преломляет карточки, текст и фото, которые едут под ним.
- **Динамическое разрешение и авто-30 fps.** Если кадры во время движения медленные, внутренний DPR снижается ступенями по 0,25. Выученный уровень сохраняется между жестами, в покое дорисовывается один чёткий кадр в полном разрешении. Если и этого мало, обновление стекла временно ограничивается 30 к/с (страница остаётся на 60).
- **Самопроверка.** После первого кадра читается пиксель. Если стекло чёрное над светлым фоном — текстура перезагружается, а при повторе включается CSS-фолбэк. Плюс все защиты из v2.

## Как это устроено (шейдер)

1. Для каждой формы считается SDF скруглённого прямоугольника **в её локальных координатах** (обратная матрица деформации) с **аналитическим градиентом**, без лишних выборок. Расстояние корректируется на длину градиента.
2. Формы объединяются через smooth-min (`k` = радиус слияния). Нормаль и параметры (ободок, толщина, фрост, тон, свечение) смешиваются с весами.
3. Профиль поверхности — «сквиркл». Сдвиг выборки фона считается по закону Снеллиуса (`ior`), плюс лёгкое увеличение центра.
4. Фон = обои (cover-кадрирование) + лист контента поверх по альфе. Фрост — дробный мип-уровень (1 выборка). Сильный фрост (>6 px) — мип плюс 4 тапа. Хроматическая аберрация только в полосе линзирования.
5. Свет: полоса блика `(1−t)^3 · facing²` плюс отражённый блик, тонкая кромка шириной ~1 device px, внутренняя тень на теневой стороне, внешняя мягкая тень.

## API сцены

```html
<img id="wall" src="wall.jpg" style="position:fixed;inset:0;width:100%;height:100lvh;object-fit:cover">
<main><canvas id="sheet"></canvas></main>        <!-- необязательно: контент, который будет преломляться -->
<nav class="tabbar" style="position:fixed;z-index:2;border-radius:31px">…</nav>
<script type="module">
  import { GlassScene } from './dist/liquid-glass-scene.min.js';
  const scene = new GlassScene({ background: document.getElementById('wall'), sheet: document.getElementById('sheet') });
  scene.add(document.querySelector('.tabbar'), { group: 1, bezel: 20, thickness: 24, blur: 1 });
  scene.add(document.querySelector('.lens'),   { group: 0, merge: 30, draggable: true });   // group 0 сливается со всеми
  // после перерисовки canvas-листа: scene.updateSheet();
</script>
```
Стеклянные элементы — обычный DOM поверх WebGL-слоя (`z-index` ≥ 2, фон прозрачный). Форма и радиус берутся из размеров и `border-radius`.

**Опции сцены** (`new GlassScene(opts)`, менять на лету — `scene.set({…})`):

| Опция | По умолч. | Описание |
|---|---|---|
| `background` | — | `img`, `canvas` или `video` — обои |
| `sheet` | `null` | `canvas` с контентом, который прокручивается |
| `fit` | `'cover'` | вписывание обоев |
| `ior` | 1.5 | показатель преломления |
| `aberration` | 0.1 | хроматическая аберрация |
| `specular` | 0.9 | яркость бликов и кромки |
| `magnify` | 0.03 | увеличение центра |
| `saturation` | 1.25 | насыщенность под стеклом |
| `tint` | 0.05 | сила адаптивной тонировки |
| `shadow` | 1 | внешняя тень |
| `light` | `'pointer'` | `'fixed'` \| `'pointer'` \| `'tilt'` |
| `maxDpr` | 2 | предел плотности пикселей |
| `dynamicResolution` | `true` | адаптивное разрешение во время движения |
| `lowPower` | `'auto'` | DPR ≤1,25, без аберрации, 30 к/с. Включается само при reduced-motion, Save-Data или слабом устройстве |
| `mode` | — | `'css'` — принудительный фолбэк |

**Опции формы** (`scene.add(el, opts)`, `scene.setShape(el, opts)`): `radius`, `bezel` (20), `thickness` (24), `blur` (1), `group` (1; 0 — сливается со всеми), `merge` (0, радиус слияния, px), `interactive` (пружина нажатия), `draggable` (перетаскивание с растяжением), `pressScale` (1.08).

**Методы:** `add`, `remove`, `setShape`, `set`, `updateSheet()`, `updateBackground()`, `invalidate()`, `animate(ms)` (перерисовка во время CSS-перехода), `setLight(mode)` (возвращает Promise — на iOS вызывать из обработчика нажатия), `setLowPower(bool)`, `destroy()`. Свойства `scene.mode` (`webgl`/`css`) и `scene.stats`.

**Доступность:** `prefers-reduced-motion` отключает пружины, `prefers-reduced-transparency` включает CSS-режим. Холст помечен `aria-hidden`, а контент остаётся в DOM.

## Поддержка браузеров

| Браузер | Режим |
|---|---|
| iOS Safari 15+ (и все браузеры iOS) | webgl-сцена: преломление, слияние, наклон |
| Android Chrome/Яндекс/Samsung | webgl-сцена |
| Chrome/Edge/Firefox/Safari на ПК | webgl-сцена |
| Нет WebGL2 / reduced-transparency / провал самопроверки | CSS: `backdrop-filter` blur + saturate над реальным DOM |

Преломление **живого произвольного DOM** без canvas-листа по-прежнему есть только в Chromium (SVG-режим v2, `demo/dom.html`). Снимок DOM в стиле html2canvas сознательно не используется: он стоит 50–300 мс на кадр и «портит» canvas в Safari (foreignObject). Вместо этого контент, который нужно преломлять, рисуется в canvas-лист — это работает на iPhone и при прокрутке ничего не стоит.

## Классический API v2 (по-прежнему в пакете)

`Glass` / `liquidGlass()` — отдельное стекло на каждый элемент с режимами `webgl` / `svg` / `css`. Его стоит использовать, если нужен SVG-режим над живым DOM в Chromium.

`new Glass(el, options)` / `liquidGlass(selector|element|list, options)` — параметры:

| Параметр | По умолч. | Описание |
|---|---|---|
| `mode` | `'auto'` | `'webgl'` \| `'svg'` \| `'css'` |
| `background` | `null` | `img`, `canvas` или `video` — источник для webgl |
| `fit` | `'cover'` | как фон вписан в свой бокс (`cover`, `contain`, `fill`) |
| `live` | `false` | обновлять текстуру каждый кадр (видео, анимация) |
| `radius` | из CSS | радиус скругления, px |
| `bezel` | 22 | ширина преломляющего ободка, px |
| `thickness` | 28 | сила преломления (максимальный сдвиг), px |
| `ior` | 1.5 | показатель преломления |
| `magnify` | 0.04 | увеличение центра |
| `blur` | 2 | фрост, px |
| `aberration` | 0.12 | хроматическая аберрация (0 — выкл.) |
| `specular` | 0.55 | яркость бликов |
| `saturation` / `brightness` | 1.35 / 1.04 | цвет фона под стеклом |
| `tint` | `[1,1,1,0.06]` | тонировка rgb (0..1) + сила |
| `light` | `[-0.6,-0.8]` | направление света |
| `adaptive` | `true` | светлый или тёмный текст по фону |
| `maxDpr` | 2 | предел плотности пикселей |
| `lowPower` | `'auto'` | `true` / `false` / `'auto'` |

Методы: `g.set({...})` — изменить параметры на лету, `g.invalidate()` — перерисовать (например, после перемещения через `transform`), `g.destroy()`.
Функции: `setLowPower(bool)`, `markBackgroundDirty(canvas)` — сообщить, что изменился canvas-фон, `detectMode()`, `capabilities()`, `perfStats`.

Элемент, который перемещается через `transform` (перетаскивание), должен вызывать `g.invalidate()` в `pointermove`, как в демо.


## Исправление v2 (1 ноября 2026): «чёрное стекло» на Android

**Причина.** `img.naturalWidth` становится известен, как только пришли заголовки картинки, — ещё до полной загрузки. На мобильной сети (фото ~400–800 КБ) первый кадр загружал в текстуру недокачанное изображение (`texImage2D: bad image data`, `glGenerateMipmap` failed), текстура оставалась «неполной» и в шейдере читалась как (0,0,0,1) — чёрный цвет. Затем её навсегда кэшировали: событие `load` не обновляло текстуру, потому что размер не менялся. Локально картинка грузилась мгновенно, поэтому ошибка не проявлялась. Воспроизведено в `tests/slownet.mjs` (эмуляция Pixel 7, 200 КБ/с): старая версия — чёрный центр стекла `[15,15,15]`, новая — `[242,241,248]`.

**Исправления.**
- Текстура грузится только из полностью декодированного источника (`img.complete`, у видео `readyState ≥ 2`). На `load` и при смене `src` она перезагружается.
- Размер текстуры ограничен `min(MAX_TEXTURE_SIZE, 2048)`, большие фото уменьшаются. Если генерация мипмапов не удалась, используется линейная фильтрация.
- Шейдер защищён от NaN: нет `pow` с отрицательным основанием, нормаль не нормализуется при нулевом градиенте, `lod` и смещения ограничены, цвет зажат в [0..1]. UV-прямоугольник проверяется на конечность.
- **Самопроверка.** После первого кадра читается пиксель в центре стекла. Если он чёрный или прозрачный, а фон под ним светлый, текстура перезагружается. При повторной неудаче все стёкла переключаются в CSS-режим (`tests/selftest.mjs`). Отдельно проверяется копирование WebGL→2D: если `drawImage` дал пустоту, включается запасной путь через `readPixels` и `putImageData`.
- В демо у ассетов есть `?v=` против кэша.
